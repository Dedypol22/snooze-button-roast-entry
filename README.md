> My alarm rang at 6 AM on a Saturday, so I filed a noise complaint — it counter-sued me for the nine minutes I snoozed.

This roast works because the alarm is not just noisy — it acts like a litigant. Instead of a tired complaint about hating mornings, the sleeper answers a 6 AM Saturday ringing with a noise complaint, and the alarm defends itself in court, counter-suing over nine snoozed minutes. The punchline lands in the last few words, turning a small, concrete number into the whole case.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The line is 118 characters, inside the 200-character limit, and the file holds exactly that line plus a trailing newline (121 bytes — the em dash is 3 bytes in UTF-8).
